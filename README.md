# Оно тебе надо

## О проекте

«Оно тебе надо» — сайт аукциона необычных вещей. Сайт предназначен для ознакомления посетителей с представленными лотами, информацией об аукционе и контактными данными.

## Структура сайта

Сайт состоит из нескольких основных разделов. В шапке страницы (`header`) расположены логотип, навигационное меню и контактная информация. Главный экран (`cover`) содержит название аукциона, фоновое изображение, описание и кнопку «Сделать ставку».

В секции «Лоты» (`lots`) размещены карточки необычных вещей. Каждая карточка содержит заголовок и описание, а также имеет собственное фоновое изображение. Для оформления карточек используются общие стили и дополнительные классы, позволяющие задавать индивидуальное оформление для разных лотов.

В разделе «Об аукционе» (`about`) представлены логотип, заголовок и текстовая информация о проекте. В нижней части страницы находится подвал (`footer`), содержащий контактные данные, навигационные ссылки и ссылки на социальные сети.

## Используемые технологии

Для создания структуры сайта использовался HTML5. С его помощью были размещены заголовки, текстовые блоки, ссылки, списки и другие элементы страницы. Также применялись семантические теги `header`, `main`, `section`, `article` и `footer`, которые помогают разделить содержимое сайта на логические части.

Для оформления страницы использовался CSS3. С его помощью были настроены шрифты, цвета, размеры элементов, отступы и фоновые изображения. Для расположения элементов применялись Flexbox и CSS Grid. Стили задавались с помощью классов, что позволило организовать оформление элементов и отдельных блоков страницы.

## Результат работы

В результате был создан одностраничный сайт аукциона с навигацией, несколькими тематическими разделами, карточками лотов и контактной информацией. В ходе работы были закреплены навыки создания HTML-разметки, оформления элементов с помощью CSS и построения сеток для расположения содержимого страницы.
